== 로그아웃 API

=== 설명

- #POST# `/api/v1/logout`
- 사용자의 로그아웃을 처리하는 API입니다.
요청 시 헤더에 포함된 FCM 토큰을 비활성화하여 더 이상 해당 기기로 푸시 알림이 전송되지 않도록 합니다.
