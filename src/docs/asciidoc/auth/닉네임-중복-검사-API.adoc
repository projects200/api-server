== 닉네임 중복 검사 API

=== 설명

- #GET# `/open/v1/nicknames/check?nickname={nickname}`
- 중복 닉네임을 검사하는 API입니다.
- 이 API는 입력받은 닉네임에 대해 다른 회원이 사용중인 닉네임인지 여부를 반환합니다. +
만약 사용중이지 않은 닉네임이라면 `true` 를 반환하고, 사용중이라면 `false` 를 반환 합니다.
