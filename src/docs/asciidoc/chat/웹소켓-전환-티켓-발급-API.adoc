== 웹소켓 전환 티켓 발급 API

=== 설명

- #POST# `/api/v1/chat-rooms/{chatroomId}/ticket`
- 회원이 다른 회원과 웹소켓으로 채팅을 하기 위해 티켓을 발행하는 api 입니다. +
해당 요청이 완료되면, 반환값인 chatTicket 을 ws 프로토콜의 파라미터로 입력하면 됩니다.
- 웹소켓 연결시 ws://chat.undabang.store/ws/chat?chatTicket={chatTicket} 으로 연결하시면 됩니다. +
(개발서버는 dev-chat.undabang.store)

=== 개발 이력

- Sprint 20 (2025-12-22): 채팅 웹소켓 고도화 기능을 개발 완료하였습니다.
