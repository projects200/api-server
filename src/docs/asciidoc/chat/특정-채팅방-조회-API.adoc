== 특정 채팅방 조회 API

=== 설명

- #GET# `/api/v1/chat-rooms/{chatroomId}/messages?prevChatId={prevChatId}&size={size}`
- 회원이 자신의 특정 채팅방을 조회하는 기능을 가진 API 입니다.
- 가장 최근 목록을 조회시에는 prevChatId 값을 전송하지 않으시면 됩니다.
- 가장 최근 목록을 조회할 경우, 가장 최근에 읽은 채팅 식별자를 최신화 하도록 구현하였습니다.
- 회원이 나간 채팅방은 조회되지 않습니다.
