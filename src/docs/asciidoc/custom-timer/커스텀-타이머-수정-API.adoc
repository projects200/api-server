== 커스텀 타이머 수정 API

=== 설명

- #PUT# `/api/v1/custom-timers/{customTimerId}`
- 커스텀 타이머 수정 API는 사용자가 생성한 커스텀 타이머의 이름과 커스텀 타이머 스텝들을 수정하는 기능을 제공합니다.
- 커스텀 타이머 스텝 수정시 스텝 순서는 0 부터 49 까지 중복없이 순차적으로 생성해야 합니다.

=== 개발 참고 사항

- <<공통-개발-참고-사항,공통 개발 참고 사항>>을 참고하세요.
- PUT은 생성 요청 DTO와 구분되는 전체 교체 요청입니다. 이름과 활성 스텝 전체를 하나의 타이머 단위로 원자적으로 변경합니다.
- 선택 `editId`(UUID)와 `editedAt`(0 이상의 UTC epoch 밀리초)은 반드시 함께 전송합니다. 둘 다 생략하면 기존 `data: null` 응답을 유지합니다.
- 동기화 성공은 `data: {updatedAt}`을 반환합니다. `updatedAt`은 밀리초 정밀도의 ISO 로컬 일시입니다. 같은 편집 ID와 작업의 재전송은 이후 수정·삭제 후에도 최초 응답 시각을 반환하며 스텝을 다시 생성하지 않습니다.
- 최초 요청의 `editedAt`이 저장된 편집 시각보다 엄격히 작으면 409 `TIMER_EDIT_CONFLICT`입니다. 같은 시각은 허용하며, 409의 `data`에는 현재 이름·활성 스텝 전체·`updatedAt`이 포함됩니다. 이름만 바꾸는 PATCH도 같은 타이머 편집 시각을 공유합니다.
- 삭제된 타이머의 새로운 편집은 편집 시각과 무관하게 410 `TIMER_DELETED`입니다. 같은 편집 ID를 이름 수정이나 삭제 등 다른 작업에 재사용하면 400 `TIMER_REQUEST_ID_REUSED`입니다.

==== 응답 상태 코드

|===
|상태 코드|설명
|200| 커스텀 타이머가 성공적으로 수정되었습니다.
|400|요청 본문 또는 동기화 메타데이터가 잘못되었습니다. 편집 ID를 다른 작업에 재사용했습니다.
|404| 회원 정보가 올바르지 않습니다. +
존재하지 않는 타이머 입니다.
|409| 최소 1개 이상의 커스텀 타이머 스텝을 보유해야 합니다. +
최대 커스텀 타이머 스텝 개수(50개)를 초과했습니다. +
스텝 순서가 잘못되었습니다. +
`TIMER_EDIT_CONFLICT`: 더 최신인 이름 또는 전체 스텝 변경이 있습니다. `data`의 현재 전체 값을 사용하세요.
|410|`TIMER_DELETED`: 삭제된 타이머는 편집할 수 없습니다.
