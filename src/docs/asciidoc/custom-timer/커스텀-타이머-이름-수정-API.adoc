== 커스텀 타이머 이름 수정 API

=== 설명

- #PATCH# `/api/v1/custom-timers/{customTimerId}`
- 커스텀 타이머 이름 수정 API는 사용자가 자신이 저장한 커스텀 타이머의 이름을 변경하는 기능을 제공합니다.

=== 개발 이력

- Sprint 10 (2025-08-23): 기능 개발이 완료되었습니다.

=== 개발 참고 사항

- <<공통-개발-참고-사항,공통 개발 참고 사항>>을 참고하세요.
- PATCH는 스텝을 유지하며 이름만 변경하지만, PUT 전체 교체와 같은 타이머 편집 시각을 공유합니다.
- 선택 `editId`(UUID)와 `editedAt`(0 이상의 UTC epoch 밀리초)은 함께 전송합니다. 둘 다 생략하면 기존 `data: null` 응답입니다. 동기화 성공은 밀리초 정밀도의 ISO 로컬 일시 `data.updatedAt`을 반환합니다.
- 같은 편집 ID와 이름 수정 작업을 재전송하면 이후 수정·삭제와 무관하게 최초 성공 시각을 반환합니다. 같은 ID를 전체 교체·삭제에 재사용하면 400 `TIMER_REQUEST_ID_REUSED`입니다.
- 저장된 편집 시각보다 엄격히 오래된 요청은 409 `TIMER_EDIT_CONFLICT`이며 `data`에 현재 이름·활성 스텝 전체·`updatedAt`이 포함됩니다. 같은 시각은 허용합니다. 삭제된 대상의 새로운 편집은 시각 비교 전에 410 `TIMER_DELETED`입니다.

==== 응답 상태 코드

|===
|상태 코드|설명
|200|커스텀 타이머의 이름이 성공적으로 변경되었습니다.
|400|요청 본문 또는 동기화 메타데이터가 잘못되었습니다. 편집 ID를 다른 작업에 재사용했습니다.
|404|회원 정보가 올바르지 않습니다. +
존재하지 않는 타이머 입니다.
|409|`TIMER_EDIT_CONFLICT`: 더 최신인 이름 또는 전체 스텝 변경이 있습니다. `data`에는 현재 전체 타이머가 포함됩니다.
|410|`TIMER_DELETED`: 삭제된 타이머는 편집할 수 없습니다.
|===
