== 커스텀 타이머 생성 API

=== 설명

- #POST# `/api/v1/custom-timers`
- 커스텀 타이머 생성 API는 사용자가 자신이 설정한 커스텀 타이머와 커스텀 타이머 스텝들을 생성하는 기능을 제공합니다.
- 커스텀 타이머 생성시 스텝 순서는 0 부터 49 까지 중복없이 순차적으로 생성해야 합니다.

=== 개발 이력

- Sprint 10 (2025-08-21): 기능 개발이 완료되었습니다.

=== 개발 참고 사항

- <<공통-개발-참고-사항,공통 개발 참고 사항>>을 참고하세요.
- 선택 `createRequestId`는 UUID이며 회원의 심플/커스텀 타이머 전체에서 같은 생성 요청을 식별합니다. 커스텀 생성 재전송은 이후 수정·삭제 후에도 최초 `customTimerId`와 `updatedAt`을 반환하며 스텝을 다시 만들지 않습니다.
- 선택 `editedAt`은 0 이상의 UTC epoch 밀리초입니다. `createRequestId` 없이 보내면 400이며, 요청 ID만 보내면 서버 현재 시각을 사용합니다. 두 필드를 모두 생략하면 기존 생성 동작을 유지합니다.
- 응답에는 기존 `customTimerId`와 함께 밀리초 정밀도의 ISO 로컬 일시 `updatedAt`이 추가됩니다. 다른 종류의 타이머에서 사용한 생성 요청 ID는 400 `TIMER_REQUEST_ID_REUSED`입니다.

==== 응답 상태 코드

|===
|상태 코드|설명
|201| 커스텀 타이머가 성공적으로 생성되었습니다.
|400|요청 본문 또는 동기화 메타데이터가 잘못되었습니다. 다른 종류의 타이머에서 사용한 생성 요청 ID입니다.
|404| 회원 정보가 올바르지 않습니다.
|409| 최소 1개 이상의 커스텀 타이머 스텝을 보유해야 합니다. +
최대 커스텀 타이머 스텝 개수(50개)를 초과했습니다. +
스텝 순서가 잘못되었습니다.
|===
