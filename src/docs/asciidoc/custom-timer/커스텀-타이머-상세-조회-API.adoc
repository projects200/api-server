== 커스텀 타이머 상세 조회 API

=== 설명

- #GET# `/api/v1/custom-timers/{customTimerId}`
- 커스텀 타이머 상세 조회 API는 사용자가 자신이 저장한 커스텀 타이머와 커스텀 타이머 스텝들을 조회하는 기능을 제공합니다.

=== 개발 이력

- Sprint 9 (2025-08-18): 기능 개발이 완료되었습니다.

=== 개발 참고 사항

- <<공통-개발-참고-사항,공통 개발 참고 사항>>을 참고하세요.
- 응답의 `updatedAt`은 이름과 활성 스텝 전체를 하나의 타이머 단위로 관리하는 서버 수정 시각입니다. 기존 ISO 로컬 일시 형식을 유지하며 밀리초 정밀도로 반환합니다.
- 본인 타이머가 삭제된 경우 404입니다. 다른 회원 소유의 타이머는 기존 403 권한 오류를 유지합니다. 삭제된 스텝, `editedAt`, 삭제 상태 필드는 응답에 노출하지 않습니다.
