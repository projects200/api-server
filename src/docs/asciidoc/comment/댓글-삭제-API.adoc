==== 응답 상태 코드

|===
|상태 코드|설명
|200|댓글이 성공적으로 삭제되었습니다.
|401|인증되지 않은 요청입니다. Access Token이 없거나 유효하지 않습니다.
|403|댓글 삭제 권한이 없습니다. 본인이 작성한 댓글만 삭제할 수 있습니다.
|404|존재하지 않는 댓글입니다.
|===
