== 점수 정책 조회 API

=== 설명
- #GET# `/open/v1/policies?type={exercise-score}`
- 운동점수 관련 정책들을 조회하는 API입니다.
- 이 API는 아래 항목에 대한 정책을 반환합니다.
* 최대 점수
* 최소 점수
* 회원 가입 시 부여받는 점수
* 운동 기록 생성 시 부여받는 점수
* 일정 기간 이상 운동 기록이 없을 경우 차감되는 점수
* 운동 기록으로 점수를 획득할 수 있는 기간
* 운동 점수가 감소 되는 한계 날짜
