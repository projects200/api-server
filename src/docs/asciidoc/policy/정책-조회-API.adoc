== 정책 조회 API

=== 설명
- #GET# `/open/v1/policy-groups/{groupName}/policies`
- 입력한 정책 그룹의 이름과 관련된 정책들을 조회하는 API입니다.
- 정책 그룹 이름으로 조회시, 아래 항목에 대한 정책을 반환합니다.

* 정책 그룹 이름
* 관련된 정책 갯수
* 관련된 정책 리스트 [정책 이름, 정책 값, 정책 단위, 정책 설명]
