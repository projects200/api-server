== 정책그룹 조회 API

=== 설명
- #GET# `/open/v1/policy-groups/{groupName}/policies`
- 입력한 정책 그룹의 이름과 관련된 정책들을 조회하는 API입니다.
- 정책 그룹 이름으로 조회시, 연관된 정책들의 정보를 반환합니다.
- 반환되는 정보들은 다음과 같습니다.

* 정책 그룹 이름
* 관련된 정책 갯수
* 관련된 정책 정보 리스트 [정책 이름, 정책 값, 정책 단위, 정책 설명]

- 현재 개발된 조회 가능한 정책 그룹 이름은 다음과 같습니다.
    * exercise-score

- exercise-score 로 조회시 받을 수 있는 정책 들의 이름과 설명은 다음과 같습니다.
    * EXERCISE_SCORE_MAX_POINTS / 회원이 가질 수 있는 최대 운동 점수
    * EXERCISE_SCORE_MIN_POINTS / 회원이 가질 수 있는 최소 운동 점수
    * SIGNUP_INITIAL_POINTS / 회원 가입 시 기본적으로 부여되는 점수
    * POINTS_PER_EXERCISE / 운동 기록 1회당 부여되는 점수 (일 1회)
    * EXERCISE_RECORD_VALIDITY_PERIOD / 점수 획득이 가능한 운동 기록의 유효 기간
    * EXERCISE_RECORD_MAX_PER_DAY / 하루에 기록할 수 있는 최대 운동 횟수
    * PENALTY_INACTIVITY_THRESHOLD_DAYS / 페널티가 시작되는 비활성 기준일 (이 기간 이상 운동 기록이 없을 경우)
    * PENALTY_SCORE_DECREMENT_POINTS / 비활성 상태일 때 매일 차감되는 점수
