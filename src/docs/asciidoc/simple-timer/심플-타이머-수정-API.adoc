== 심플 타이머 수정 API

=== 설명

- #PATCH# `/api/v1/simple-timers/{simpleTimerId}`
- 심플 타이머 수정 API는 사용자가 심플 타이머의 시간을 수정하는 기능을 제공합니다.

=== 개발 이력

- Sprint 9 (2025-08-14): 기능 개발이 완료되었습니다.

=== 개발 참고 사항

- <<공통-개발-참고-사항,공통 개발 참고 사항>>을 참고하세요.
- 기존 요청은 `time`만 보내며 성공 응답의 `data`는 기존처럼 null입니다. 같은 시간으로 수정하면 서버 수정 시각도 바뀌지 않습니다.
- 동기화 요청은 UUID `editId`와 0 이상 UTC Unix 밀리초 `editedAt`을 함께 보냅니다. 둘 중 하나만 보내거나 음수 시각을 보내면 400입니다. 성공 응답은 `data.updatedAt`을 포함합니다.
- 동일한 수정 키의 재시도는 현재 값·삭제 상태·시각 비교보다 먼저 최초 성공 시각을 반환합니다. 같은 키를 삭제에 재사용하면 `TIMER_REQUEST_ID_REUSED`(400)입니다.
- 처음 보는 수정 키는 삭제된 소유 타이머에 대해 `TIMER_DELETED`(410)를 반환합니다. 현재 유효 수정 시각보다 엄격하게 오래된 요청은 `TIMER_EDIT_CONFLICT`(409)이며 `data`에 현재 `simpleTimerId`, `time`, `updatedAt`을 담습니다. 같은 기기 시각은 수락합니다.
- 기존 행의 기기 시각이 없으면 서버 수정 시각을 기존 서버 시간대로 해석하여 비교합니다. 조회·충돌 응답은 기기 시각이나 삭제 행을 노출하지 않습니다.

==== 응답 상태 코드

|===
|상태 코드|설명
|200|심플 타이머 정보가 성공적으로 수정되었습니다.
|400|입력 정보가 정확하지 않습니다.
|404|회원이 존재하지 않습니다. +
존재하지 않는 타이머 입니다.
|409|기기 수정 시각이 현재 값보다 오래되었습니다. 현재 타이머가 `data`에 포함됩니다.
|410|소유한 타이머가 이미 삭제되었습니다(처음 보는 동기화 수정 키).
|===
