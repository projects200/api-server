== 심플 타이머 조회 API

=== 설명

- #GET# `/api/v1/simple-timers`
- 심플 타이머 조회 API는 사용자가 자신이 저장한 심플 타이머 정보를 조회하는 기능을 제공합니다.

=== 개발 이력

- Sprint 9 (2025-08-12): 기능 개발이 완료되었습니다.

=== 개발 참고 사항

- <<공통-개발-참고-사항,공통 개발 참고 사항>>을 참고하세요.
- 목록은 삭제되지 않은 본인 타이머만 시간(초) 오름차순으로 반환합니다. 0개 목록과 같은 시간의 여러 타이머를 허용합니다.
- 각 항목은 `simpleTimerId`, `time`, `updatedAt`을 포함합니다. `updatedAt`은 밀리초 정밀도의 ISO 로컬 서버 일시입니다. 기기 수정 시각과 삭제 행은 노출하지 않습니다.
