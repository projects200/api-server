== 심플 타이머 생성 API

=== 설명

- #POST# `/api/v1/simple-timers`
- 심플 타이머 생성 API는 사용자가 심플 타이머의 시간을 생성하는 기능을 제공합니다.
- 사용자가 생성할 수 있는 시간은 1 ~ 3599(초) 사이의 양수값입니다.

=== 개발 이력

- Sprint 9 (2025-08-15): 기능 개발이 완료되었습니다.

=== 개발 참고 사항

- <<공통-개발-참고-사항,공통 개발 참고 사항>>을 참고하세요.
- `createRequestId`가 없는 기존 요청은 최대 개수(기본 6개)에서 `SIMPLE_TIMER_MAX_COUNT_VIOLATION`(409)으로 거절합니다.
- 동기화 요청은 UUID `createRequestId`를 보냅니다. `editedAt`은 선택적인 0 이상 UTC Unix 밀리초이며, 생략하면 서버 현재 시각을 사용합니다. `editedAt`만 보내면 400입니다.
- 같은 회원의 같은 생성 키는 이후 수정·삭제·개수 정리 후에도 최초 `simpleTimerId`와 `updatedAt`을 반환합니다. 두 타이머 종류가 생성 키를 공유하므로 다른 종류에서 사용한 키는 `TIMER_REQUEST_ID_REUSED`(400)입니다.
- 동기화 생성은 먼저 수락한 뒤 유효 수정 시각 내림차순, ID 내림차순으로 최대 개수만 남깁니다. 기존 행은 서버 수정 시각을 사용합니다. 새 타이머가 오래되어 즉시 정리되어도 최초 생성 응답은 유지됩니다.
- 타이머가 0개이거나 같은 시간의 타이머가 여러 개여도 유효합니다. `updatedAt`은 밀리초 정밀도의 ISO 로컬 일시이며 `editedAt`과 다른 서버 시각입니다.

==== 응답 상태 코드

|===
|상태 코드|설명
|201|심플 타이머가 성공적으로 생성되었습니다.
|400|입력 정보가 정확하지 않거나 생성 메타데이터가 잘못되었습니다. 다른 타이머 종류에 사용한 생성 키를 재사용했습니다.
|404|회원이 존재하지 않습니다.
|409|최대 심플 타이머 개수(6개)를 초과했습니다.
|===
