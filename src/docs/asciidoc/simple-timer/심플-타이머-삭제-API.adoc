== 심플 타이머 삭제 API

=== 설명

- #DELETE# `/api/v1/simple-timers/{simpleTimerId}`
- 심플 타이머 삭제 API는 사용자가 심플 타이머를 삭제하는 기능을 제공합니다.

=== 개발 이력

- Sprint 9 (2025-08-16): 기능 개발이 완료되었습니다.

=== 개발 참고 사항

- <<공통-개발-참고-사항,공통 개발 참고 사항>>을 참고하세요.
- 본문이 없거나 `{}`인 기존 요청은 성공 시 기존처럼 `data: null`을 반환합니다. 이미 삭제된 타이머는 기존처럼 404입니다.
- 동기화 삭제는 선택적 JSON 본문에 UUID `editId`와 0 이상 UTC Unix 밀리초 `editedAt`을 함께 보냅니다. 부분 메타데이터·음수 시각은 400이며 성공 응답은 `data.updatedAt`입니다.
- 삭제는 기기 시각과 무관하게 수정보다 우선합니다. 소유한 삭제 행에 새 삭제 키를 보내도 성공하며 기존 삭제 시각을 보존합니다.
- 같은 삭제 키의 재시도는 최초 성공 시각을 반환합니다. 수정에 사용한 키를 삭제에 재사용하면 `TIMER_REQUEST_ID_REUSED`(400)입니다.
- 마지막 타이머도 삭제할 수 있습니다. 회원이 없거나 타이머가 없거나 다른 회원의 소유라면 404입니다.
