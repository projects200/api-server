== 운동 장소 이름 수정 API

=== 설명

- #PATCH# `/api/v1/exercise-locations/{locationId}`
- 회원이 자신이 등록한 운동 장소의 이름을 수정하는 API 입니다.
- 회원은 이미 보유하고 있는 운동 장소명으로 새로운 운동 장소 이름을 설정할 수 없습니다.
- 운동 장소 명은 최소 1글자 최대 100글자 이내 여야 합니다.
