== 운동 장소 생성 API

=== 설명

- #POST# `/api/v1/exercise-locations`
- 회원이 자신의 운동 장소를 등록하는 API 입니다.
- 회원은 최대 10개의 운동장소를 생성할 수 있습니다.
- 회원은 이미 존재하는 운동 장소명으로 새로운 운동장소를 생성할 수 없습니다.
- 운동 장소 명은 최소 1글자 최대 100글자 이내 여야 합니다.
- 운동 장소 주소명은 최소 1글자 최대 255글자 이내 여야 합니다.
