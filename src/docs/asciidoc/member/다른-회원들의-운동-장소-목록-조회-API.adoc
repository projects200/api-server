== 다른 회원들의 운동 장소 목록 조회 API

=== 설명

- #GET# `/api/v1/members`
- 지도에서 확인 가능한 다른 회원들의 운동 장소 목록을 조회하는 API 입니다.

=== 개발 이력

- Sprint 12 (2025-09-22): 운동 장소를 생성한 모든 회원의 운동장소를 반환하는 API 를 개발하였습니다. +
추후 해당 기능에 필터링이 적용되어서 근처 N km 이내의 회원을 검색하는 기능이 추가될 예정입니다.
- Sprint 15 (2025-10-27): 다른 회원들의 운동장소 조회시 내가 차단한 회원 + 나를 차단한 회원은 상호간의 조회가 되지 않도록 설정하였습니다.
- Sprint 22 (2026-01-14): 현재 위치의 왼쪽 상단, 오른쪽 하단의 위도, 경도에 포함된 회원의 운동장소 조회로 수정하였습니다.
