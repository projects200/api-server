== 운동 기록 삭제 API

=== 설명
- #DELETE# `/api/v1/exercises/{exerciseId}`
- 운동 기록 데이터를 삭제하는 API입니다.
- 이 API를 통해 사용자는 자신이 생성한 운동 기록을 삭제할 수 있습니다.

=== 오프라인 동기화 계약
- 선택 쿼리 `editId` UUID를 보내면 `data.exerciseId`, `data.version`을 반환합니다.
  생략하면 기존 `SUCCESS` 및 `data: null` 응답을 유지합니다. `baseVersion`은 요구하지 않습니다.
- 같은 키의 재시도는 원본 응답을 반환합니다. 다른 작업/대상에 재사용한 키는 400입니다.
  이미 삭제된 본인 기록도 성공하되 버전을 다시 증가시키지 않습니다. 미존재/타인 기록을 성공으로 처리하지 않습니다.
- 삭제는 늦은 본문 편집/사진 업로드보다 우선하며 기록을 부활시키지 않습니다. 원본 성공 영수증의 재생은 허용합니다.
- 관련 사진은 같은 DB 트랜잭션에서 숨기고 객체 삭제 작업을 영속화합니다. S3 삭제는 커밋 후 및 스케줄러에서 재시도합니다.
  객체 정리 실패는 이미 확정된 DB 삭제를 되돌리지 않습니다. 이미 획득한 점수는 회수하지 않습니다.

==== 응답 상태 코드
|===
|상태 코드|설명
|200|삭제 완료. editId가 있으면 기록 ID/버전, 없으면 null 데이터입니다.
|400|입력값 검증에 실패했습니다.
|403|운동 기록에 접근 권한이 없습니다
|404|운동 기록이나 회원이 존재하지 않습니다.
