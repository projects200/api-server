== 운동 기록 이미지 삭제 API

=== 설명
- #DELETE# `/api/v1/exercises/{exerciseId}/pictures`
- 운동 기록 이미지 데이터를 삭제하는 API입니다.
- 이 API를 통해 사용자는 자신이 저장한 이미지 데이터를 삭제할 수 있습니다.

=== 오프라인 동기화 계약
- 기존 `pictureIds` 쿼리에 선택 `editId` UUID를 추가할 수 있습니다.
  키가 있으면 `data.exerciseId`, `data.version`을 반환하며 없으면 기존 null 데이터 성공 응답을 유지합니다.
- 모든 사진 ID는 지정한 본인 운동에 속해야 합니다. 다른 기록의 ID가 하나라도 있으면 전체 요청을 거절합니다.
  이미 삭제된 사진도 소유권을 검증하며 다시 삭제해도 안전합니다. 요청 ID 해시는 사진 ID 순서/중복을 무시합니다.
- 같은 키/목록/대상 재시도는 원본 응답을 재생합니다. 다른 목록/작업/대상으로 재사용하면 400입니다.
  실제 활성 사진이 삭제될 때만 운동 버전을 한 번 증가시킵니다.
- DB soft delete와 객체 키 정리 작업을 함께 커밋한 뒤 S3 삭제를 시도합니다. 실패한 작업은 DB에 남기고
  5분 후 다시 처리할 수 있으며 스케줄러는 기본 60초마다 최대 50건을 조회합니다.
  S3 실패를 정리 완료로 표시하지 않습니다. 사진은 DB 삭제 직후 조회에서 숨겨집니다.
