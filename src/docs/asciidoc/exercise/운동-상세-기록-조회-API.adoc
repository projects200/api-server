== 운동 상세 기록 조회 API

=== 설명
- #GET# `/api/v1/exercises/{exerciseId}`
- 운동 상세 기록을 조회하는 API입니다. 운동 기록의 ID를 통해 해당 운동 기록의 상세 정보를 가져옵니다.

=== 개발 참고 사항
- <<공통-개발-참고-사항,공통 개발 참고 사항>>을 참고하세요.
- 운동 기록의 ID는 `exerciseId` 경로 매개 변수로 전달됩니다.
- 이 API는 운동 기록의 상세 정보와 관련된 이미지 URL을 포함하여 응답합니다.
- 사진은 `pictureDataList`에 저장된 Picture ID와 URL로 반환됩니다. 동기화 업로드의 `pictureId`와 동일한 ID입니다.
- 응답 `version`은 현재 본문/사진 상태의 버전입니다. 편집 시 이 값을 `baseVersion`으로 보내세요.
  조회 후 다른 기기가 수정했다면 서버는 409로 거절합니다. 버전 없는 구 캐시에 새 GET 버전을 끼워 넣어 자동 덮어쓰지 마세요.
  기존 데이터는 스키마 업그레이드 시 버전 0에서 시작하며 삭제된 기록은 상세 조회하지 않습니다.
