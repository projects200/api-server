== 운동 상세 기록 조회 API

=== 설명
- #GET# `/api/v1/exercises/{exerciseId}`
- 운동 상세 기록을 조회하는 API입니다. 운동 기록의 ID를 통해 해당 운동 기록의 상세 정보를 가져옵니다.

=== 개발 참고 사항
- <<공통-개발-참고-사항,공통 개발 참고 사항>>을 참고하세요.
- 운동 기록의 ID는 `exerciseId` 경로 매개 변수로 전달됩니다.
- 이 API는 운동 기록의 상세 정보와 관련된 이미지 URL을 포함하여 응답합니다.
- 사진은 `pictureDataList`에 저장된 Picture ID와 URL로 반환됩니다. 동기화 업로드의 `pictureId`와 동일한 ID입니다.
- 응답 `version`은 현재 본문/사진 상태의 버전입니다. 편집 시 이 값을 `baseVersion`으로 보내세요.
  시각 없는 기존 요청 또는 과거 본문 시각이 불명인 행에는 버전 일치가 필요합니다. 버전 없는 구 캐시에 새 GET 버전을 끼워 넣어 자동 덮어쓰지 마세요.
  기존 데이터는 동기화 스키마 업그레이드 시 버전 0에서 시작하며 삭제된 기록은 상세 조회하지 않습니다.
- 응답 `editedAt`은 본문 저장 때 고정한 양수 UTC epoch 밀리초 정수이며, 과거 편집 시각을 모르면 명시적 `null`입니다.
  누락도 불명으로 취급하며 0/현재 시각/생성 시각으로 대체하지 마세요. 사진 추가/삭제는 이 시각을 변경하지 않습니다.
  시각이 알려진 두 본문은 엄격히 최신인 사용자 저장이 우선하며 동률은 서버 본문을 유지합니다. 충돌의 GET은 사진 매핑도 함께 보존하세요.
- 이 GET의 일반 404/권한 오류는 원격 삭제의 증거가 아닙니다. 새로운 PATCH의 명명된 410 `EXERCISE_DELETED`로 삭제를 구분합니다.
