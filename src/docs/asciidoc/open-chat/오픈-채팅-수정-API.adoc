== 오픈 채팅 수정 API

=== 설명

- #PATCH# `/api/v1/open-chat`
- 회원이 자신의 카카오톡 오픈 채팅 URL을 수정하는 API 입니다.
- 회원은 이미 존재하는 오픈 채팅 URL로 오픈 채팅 URL을 수정할 수 없습니다.
- 오픈 채팅은 반드시 카카오톡에서 제공하는 URL을 입력해야 합니다.

==== 응답 상태 코드

|===
|상태 코드|설명
|200|리소스가 성공적으로 수정되었습니다.
|401|인증되지 않은 요청입니다. Access Token이 없거나 유효하지 않습니다.
|403|권한이 없는 요청입니다.
|404|존재하지 않는 회원이거나 오픈 채팅방을 찾을 수 없습니다.
|409|이미 사용중인 오픈 채팅 URL입니다.
|===
